# 📊 Balance

**Balance** es una aplicación web desarrollada en **PHP** que permite gestionar y registrar ingresos y egresos de manera organizada, almacenando la información en una base de datos relacional.  

Este sistema facilita el control financiero mediante un panel interactivo que muestra categorías, subcategorías y totales, ofreciendo una visión clara del estado económico.

---

## 🛠 Funcionalidades

- Registro de **ingresos** y **egresos** con fecha, categoría, subcategoría e importe.
- Consulta de operaciones filtradas por tipo.
- Manejo de categorías y subcategorías dinámicas.
- Interfaz adaptable con secciones reutilizables (layout con header, nav y footer).
- Gestión de sesiones para control de acceso.

---

## 📋 Tecnologías utilizadas

- **Lenguaje backend:** PHP 7+
- **Base de datos:** MySQL / MariaDB
- **Conexión:** Extensión `MySQLi` o `PDO` (según configuración en `conexion.php`)
- **Servidor web:** Apache (XAMPP)
- **Frontend:** HTML5, CSS3, JavaScript
